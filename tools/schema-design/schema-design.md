# Database Design Tools
A curated list of tools for designing, visualizing, and documenting database schemas.

## Diagramming and Schema Modeling
**draw.io**
**Type**: Visual diagramming tool

Create entity-relationship diagrams and other visual representations of database structures.

**Useful for:**

* Building diagrams with flexible layouts.
* Documenting relationships between entities.
* Creating visual technical documentation.

**ERDPlus**
**Type**: Database modeling tool

Create entity-relationship diagrams and relational schemas.

**Useful for:**

* Practicing conceptual database design.
* Exploring the transition from ER diagrams to relational schemas.
* Learning database modeling fundamentals.
  
**dbdiagram.io**
**Type**: Text-based schema modeling tool

Define and visualize database schemas using DBML.

**Useful for:**

* Documenting relational database structures.
* Keeping schema definitions in version control.
* Creating diagrams from a text-based schema description.

## Comparison

## Choosing a Tool
Consider the following before choosing a database design tool:

* Supported modeling techniques.
* Editable source and export formats.
* Compatibility with your target database engine.
* Collaboration and version-control capabilities.
* Pricing and usage limitations.
